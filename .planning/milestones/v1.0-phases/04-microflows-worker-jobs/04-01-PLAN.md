    ```python
    from dataclasses import dataclass, field
    from enum import Enum
    from typing import Any

    class Opcode(Enum):
        LOAD = "load"           # load value from context source path
        LOAD_CONST = "ldc"      # load a literal constant
        COMPARE = "cmp"         # compare top-of-stack values using operator
        JUMP_IF_FALSE = "jif"   # jump to target if false
        JUMP = "jmp"            # unconditional jump to target
        CALL = "call"           # call action by name with params
        RETURN = "ret"          # return from microflow with result

    @dataclass
    class Instruction:
        opcode: Opcode
        args: dict = field(default_factory=dict)
        target: int | None = None  # instruction index for jump instructions

    @dataclass
    class Bytecode:
        instructions: list[Instruction]
        step_ids: list[str]     # step id at each instruction index
        constants: dict[str, Any] = field(default_factory=dict)
        version: int = 1

    @dataclass
    class Trigger:
        event: str

    @dataclass
    class ConditionStep:
        id: str
        source: str             # dot-path into context payload, e.g. "payload.total"
        operator: str           # "eq", "neq", "gt", "gte", "lt", "lte"
        value: Any              # literal value to compare against
        then: str               # step_id to jump to if condition true
        else_: str              # step_id to jump to if condition false

    @dataclass
    class ActionStep:
        id: str
        action: str             # action name, e.g. "order.approve"
        params: dict            # parameters to pass to the action

    @dataclass
    class SwitchStep:
        id: str
        source: str
        cases: dict[str, str]   # value -> step_id
        default: str            # step_id when no case matches

    @dataclass
    class MicroflowDef:
        name: str
        version: int
        triggers: list[Trigger]
        steps: list[ConditionStep | ActionStep | SwitchStep]
        description: str = ""
    ```

    The `steps` list in `MicroflowDef` uses a union type — each step has a `type` discriminator string field set by the compiler during parsing. The `Model` suffix on step types is NOT needed since they're already in the `models` namespace.

    **Design rationale per D-03:** YAML-based DSL, not Python-inspired. The step model uses structured fields (source, operator, value) instead of Python expressions. The ActionStep uses named action strings + params dict instead of arbitrary function calls.

    Create `mcf/src/ccam_mcf/compiler.py` implementing the `compile_microflow(yaml_str: str) -> Bytecode` function.

    **Compilation algorithm:**

    1. **Parse YAML** — `yaml.safe_load(yaml_str)`. Raise `CompileError` if YAML is not a dict or is empty.

    2. **Validate top-level structure:**
       - `name` must be a non-empty string
       - `version` must be a positive int
       - `steps` must be a non-empty list of dicts
       - Each step must have `id` (unique within microflow), `type` (one of "condition", "action", "switch")
       - `triggers` is optional; if present, each trigger must have `event` (non-empty string)

    3. **Validate each step by type:**

       **Condition step** (`type: condition`):
       - Required: `if.source` (string), `if.operator` (one of: eq, neq, gt, gte, lt, lte), `if.value` (any), `then` (string), `else` (string)
       - `then` and `else` must reference valid step_ids (resolve cross-references after all steps parsed)

       **Action step** (`type: action`):
       - Required: `action` (string, non-empty), `params` (dict, may be empty)

       **Switch step** (`type: switch`):
       - Required: `switch.source` (string), `switch.cases` (dict-of-string->string), `switch.default` (string)
       - All case values and default must reference valid step_ids

    4. **Resolve DAG to linear instruction list:**
       - Build adjacency from step DAG using then/else/default refs
       - Start from first step in `steps` list as entry point
       - Depth-first traversal, emitting instructions:
         - `condition` → LOAD source, LOAD_CONST value, COMPARE operator, JUMP_IF_FALSE else_target
         - `action` → LOAD_CONST params, CALL action_name
         - `switch` → LOAD source, then for each case: LOAD_CONST case_value, COMPARE eq, JUMP_IF_FALSE next_case, JUMP target
       - Each branch ends with `RETURN`
       - Dead code detection: warn if a step has no incoming references (don't fail — just skip)

    5. **Cycle detection:** DAG must be acyclic — per D-01, the MCF-03 safety layer (loop detection) is deferred, but the compiler should still detect cycles since they'd break the linearization. If a cycle is detected, raise `CompileError("Cycle detected involving step: {step_id}")`.

    6. **Return `Bytecode`** with instructions, step_ids (one per instruction entry position), and constants dict.

    **Error messages must include:** the specific step_id (when applicable), the field path that failed validation, and the expected vs actual value.

    **Example microflow YAML:**
    ```yaml
    name: validate_and_process_order
    version: 1
    triggers:
      - event: order.created
    steps:
      - id: check_total
        type: condition
        if:
          source: payload.total
          operator: gt
          value: 0
        then: approve
        else: reject
      - id: approve
        type: action
        action: order.approve
        params:
          reason: "Valid order total"
      - id: reject
        type: action
        action: order.reject
        params:
          reason: "Negative or zero total"
    ```

    **Do NOT implement:**
    - MCF-03 safety layer checks (no privilege escalation checks, no recursion depth limiting beyond step count, no sandboxing) — deferred per D-01
    - Variable interpolation in field paths
    - Nested `steps` (flattened linear list only)
    - Template rendering or dynamic YAML generation

    **3.1 — mcf/src/ccam_mcf/executor.py:**

    ```python
    """Deterministic bytecode executor for compiled microflows."""
    from typing import Any, Callable
    from ccam_mcf.models import Bytecode, Instruction, Opcode
    from ccam_mcf.exceptions import ExecError


    class MicroflowContext:
        """Execution context holding input payload, memory, and action registry.

        payload: dict — input data for the microflow (e.g., event payload)
        memory: dict — runtime variable store for step output sharing
        actions: dict[str, Callable] — named action handlers registered externally
        """
        def __init__(
            self,
            payload: dict | None = None,
            memory: dict | None = None,
            actions: dict[str, Callable] | None = None,
        ):
            self.payload = payload or {}
            self.memory = memory or {}
            self.actions = actions or {}


    class BytecodeExecutor:
        """Deterministic bytecode executor.

        Executes Bytecode instructions sequentially, maintaining determinism
        (same bytecode + same context → same output across all runs).

        The executor uses a simple stack machine model:
        - LOAD/LOAD_CONST push values onto the value stack
        - COMPARE pops two values, pushes boolean result
        - JUMP_IF_FALSE conditionally jumps based on top-of-stack
        - CALL pops params, invokes registered action, pushes result
        - RETURN pops final result and returns it
        """

        def __init__(self, bytecode: Bytecode, context: MicroflowContext):
            self._bytecode = bytecode
            self._context = context
            self._ip = 0                        # instruction pointer
            self._stack: list[Any] = []         # value stack
            self._call_stack: list[int] = []    # return address stack (reserved for future use)

        def run(self, seed: int | None = None) -> Any:
            """Execute bytecode deterministically.

            Args:
                seed: Optional RNG seed for deterministic randomness in actions.
                      Not used internally (executor is pure) but passed through
                      to action handlers.

            Returns:
                Value returned by the final RETURN instruction.
                If no RETURN is reached, returns None.

            Raises:
                ExecError: On action not found, field access failure, etc.
            """
            self._ip = 0
            self._stack.clear()

            while self._ip < len(self._bytecode.instructions):
                instr = self._bytecode.instructions[self._ip]

                if instr.opcode == Opcode.LOAD:
                    self._execute_load(instr)
                elif instr.opcode == Opcode.LOAD_CONST:
                    self._execute_load_const(instr)
                elif instr.opcode == Opcode.COMPARE:
                    self._execute_compare(instr)
                elif instr.opcode == Opcode.JUMP_IF_FALSE:
                    self._execute_jump_if_false(instr)
                elif instr.opcode == Opcode.JUMP:
                    self._execute_jump(instr)
                elif instr.opcode == Opcode.CALL:
                    self._execute_call(instr)
                elif instr.opcode == Opcode.RETURN:
                    return self._execute_return()
                else:
                    raise ExecError(f"Unknown opcode: {instr.opcode}")

                self._ip += 1

            return None  # No RETURN reached — degenerate microflow

        def _resolve_source(self, source: str) -> Any:
            """Resolve dot-notation path against context objects.

            Supports:
            - "payload.field.nested" — walks context.payload
            - "memory.key" — walks context.memory
            """
            if not source:
                raise ExecError(f"Empty source path")

            parts = source.split(".")
            root_name = parts[0]

            if root_name == "payload":
                obj = self._context.payload
            elif root_name == "memory":
                obj = self._context.memory
            else:
                raise ExecError(f"Unknown source root '{root_name}'. Use 'payload.' or 'memory.'")

            for part in parts[1:]:
                if isinstance(obj, dict):
                    if part not in obj:
                        raise ExecError(f"Field '{part}' not found in {root_name} path '{source}'")
                    obj = obj[part]
                else:
                    raise ExecError(f"Cannot navigate into non-dict value at '{part}' in path '{source}'")

            return obj

        def _execute_load(self, instr: Instruction) -> None:
            source = instr.args.get("source", "")
            value = self._resolve_source(source)
            self._stack.append(value)

        def _execute_load_const(self, instr: Instruction) -> None:
            value = instr.args.get("value")
            self._stack.append(value)

        def _execute_compare(self, instr: Instruction) -> None:
            if len(self._stack) < 2:
                raise ExecError("COMPARE requires 2 values on stack")
            b = self._stack.pop()
            a = self._stack.pop()
            operator = instr.args.get("operator", "eq")

            COMPARE_OPS = {
                "eq": a == b,
                "neq": a != b,
                "gt": a > b,
                "gte": a >= b,
                "lt": a < b,
                "lte": a <= b,
            }
            if operator not in COMPARE_OPS:
                raise ExecError(f"Unknown operator '{operator}'")
            self._stack.append(COMPARE_OPS[operator])

        def _execute_jump_if_false(self, instr: Instruction) -> None:
            if not self._stack:
                raise ExecError("JUMP_IF_FALSE requires a value on stack")
            condition = self._stack.pop()
            if not condition:
                if instr.target is not None:
                    self._ip = instr.target
                else:
                    raise ExecError("JUMP_IF_FALSE missing target")

        def _execute_jump(self, instr: Instruction) -> None:
            if instr.target is not None:
                self._ip = instr.target
            else:
                raise ExecError("JUMP missing target")

        def _execute_call(self, instr: Instruction) -> None:
            action_name = instr.args.get("action", "")
            if not action_name:
                raise ExecError("CALL missing action name")

            handler = self._context.actions.get(action_name)
            if handler is None:
                raise ExecError(f"Unknown action '{action_name}'. No handler registered in context.actions.")

            params = instr.args.get("params", {})
            try:
                result = handler(params)
                self._stack.append(result)
            except Exception as e:
                raise ExecError(f"Action '{action_name}' failed: {e}")

        def _execute_return(self) -> Any:
            if self._stack:
                return self._stack.pop()
            return None
    ```

    **Design notes:**
    - Stack-based VM: simple, testable, deterministic
    - Source paths use `payload.` and `memory.` prefix convention per D-03 (structured, not Pythonic)
    - Action registry is an explicit dict — actions are injected externally (not imported), keeping the library standalone
    - Seed is accepted but not used internally — the executor is pure; determinism derives from the bytecode + context being identical
