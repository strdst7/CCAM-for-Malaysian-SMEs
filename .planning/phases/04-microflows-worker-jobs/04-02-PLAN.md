<objective>
Build the ARQ-based worker job infrastructure that wraps the microflow DSL library (ccam-mcf) for FIFO job execution with retry, dead-letter queue, and idempotency.

**Purpose:** Provide the execution substrate for microflows — workers consume YAML microflow definitions, execute them deterministically via the DSL bytecode executor, and track job state through a completion/retry/DLQ lifecycle. The system reuses the existing ARQ Redis pool and FastAPI lifespan.

- ARQ worker function and WorkerSettings for microflow execution
- Job enqueue/status/retry/DLQ lifecycle

    **2.2 — backend/src/ccam_backend/workers/mcf_worker.py:**

    ```python
    """Microflow execution worker — consumes ARQ jobs, executes DSL bytecode, tracks status."""
    from datetime import datetime, timezone
    from sqlalchemy import select, update
    from ccam_backend.database import async_session_factory
    from ccam_backend.models.worker_job import WorkerJob
    from ccam_backend.redis_client import _redis_settings_from_url
    from ccam_backend.config import settings
    from ccam_mcf import compile_microflow, BytecodeExecutor, MicroflowContext

    async def execute_microflow_job(ctx, microflow_yaml: str, payload: dict | None,
                                    job_id: str, idempotency_key: str | None = None) -> dict:
        """Execute a microflow DSL definition as an ARQ worker job.

        Idempotency: if idempotency_key is provided and a completed job exists
        with the same key, return the stored result without re-executing.

        Status lifecycle: queued → running → completed|failed|dlq

        Retry/DLQ: ARQ retries on function exception. After max_retries
        attempts, this function catches the final failure and sets status to 'dlq'.
        """
        async with async_session_factory() as db:
            # --- Idempotency check ---
            if idempotency_key:
                result = await db.execute(
                    select(WorkerJob).where(
                        WorkerJob.idempotency_key == idempotency_key,
                        WorkerJob.status == "completed",
                    )
                )
                existing = result.scalar_one_or_none()
                if existing is not None:
                    # Return stored result without re-execution
                    return {"status": "completed", "job_id": existing.id,
                            "result": existing.result_json, "replayed": True}

            # --- Fetch job record ---
            result = await db.execute(select(WorkerJob).where(WorkerJob.id == job_id))
            job = result.scalar_one_or_none()
            if job is None:
                raise ValueError(f"Job {job_id} not found")

            # --- Mark as running ---
            job.status = "running"
            job.started_at = datetime.now(timezone.utc)  # type: ignore[arg-type]
            await db.flush()

            try:
                # --- Compile YAML to bytecode ---
                bytecode = compile_microflow(microflow_yaml)

                # --- Create execution context ---
                context = MicroflowContext(
                    payload=payload or {},
                    memory={},
                    actions={},  # Actions registered separately per deployment
                )

                # --- Execute deterministically ---
                executor = BytecodeExecutor(bytecode, context)
                result_value = executor.run(seed=42)

                # --- Mark as completed ---
                job.status = "completed"
                job.result_json = {"output": result_value}
                job.completed_at = datetime.now(timezone.utc)  # type: ignore[arg-type]

                await db.commit()
                return {"status": "completed", "job_id": job_id,
                        "result": result_value, "replayed": False}

            except Exception as e:
                job.retry_count += 1
                job.error_message = str(e)

                # --- Check if max retries exhausted → DLQ ---
                # ARQ provides ctx['job_try'] (1-indexed attempt number).
                # The worker's max_tries config determines maximum attempts.
                attempt = ctx.get("job_try", 1)
                max_tries = getattr(ctx.get("worker"), "max_tries", 5) if ctx.get("worker") else 5

                if attempt >= max_tries:
                    job.status = "dlq"
                    job.completed_at = datetime.now(timezone.utc)  # type: ignore[arg-type]
                    await db.commit()
                    return {"status": "dlq", "job_id": job_id, "error": str(e)}
                else:
                    # Let ARQ handle the retry (exception propagates → ARQ retries)
                    job.status = "failed"
                    await db.commit()
                    raise


    class WorkerSettings:
        """ARQ worker configuration for microflow execution."""
        functions = [execute_microflow_job]
        redis_settings = _redis_settings_from_url(settings.redis_url)
        max_tries = 5                # Total attempts (initial + 4 retries)
        job_retry_after = 60         # Base delay seconds (ARQ applies exponential backoff)
        keep_result = 86400          # Keep job results for 1 day
        keep_result_failed = 86400   # Keep failed job results for 1 day
    ```

    **IMPORTANT re: actions registry:** The `actions={}` in `MicroflowContext` means the executor will fail at runtime if a microflow step calls an action that isn't registered. This is intentional — action registration is deployment-specific and will be wired in future phases. For Phase 4, the worker demonstrates the full lifecycle (compile → execute → status tracking). When an action call fails due to unknown action, it raises an `ExecError` which the worker catches and treats as a job failure (retry → DLQ).

    **ARQ worker invocation:** The worker process is started separately via:
    ```bash
    arq ccam_backend.workers.mcf_worker.WorkerSettings
    ```
    This runs independently from the FastAPI server. The FastAPI server enqueues jobs via `arq_pool.enqueue_job()`. Both processes share the same Redis instance.

    **Do NOT implement:**
    - Action handler registration (deferred — actions are domain-specific, not part of the core DSL worker)
    - MCF-03 safety layer checks (deferred per D-01)
    - MCF-04 simulator validation gate (deferred per D-01)
    - Cron/scheduled job triggers (out of scope for Phase 4)
    - Fan-out or composite jobs

    ```python
    from fastapi import APIRouter, Depends, HTTPException, Request
    from sqlalchemy import select, func
    from sqlalchemy.ext.asyncio import AsyncSession
    from ccam_backend.api.deps import get_db, get_redis_client
    from ccam_backend.auth.middleware import verify_hmac
    from ccam_backend.models.worker_job import WorkerJob
    from ccam_backend.schemas.jobs import JobEnqueueRequest, JobResponse, JobListResponse
    from ccam_backend.audit.logger import AuditLogger
    import redis.asyncio as aioredis

    router = APIRouter(tags=["jobs"])


    def _job_to_response(job: WorkerJob) -> JobResponse:
        return JobResponse(
            id=job.id,
            tenant_id=job.tenant_id,
            status=job.status,
            microflow_yaml=job.microflow_yaml,
            payload=job.payload,
            idempotency_key=job.idempotency_key,
            result=job.result_json,
            error_message=job.error_message,
            retry_count=job.retry_count,
            max_retries=job.max_retries,
            created_at=job.created_at,            # type: ignore[arg-type]
            started_at=job.started_at,             # type: ignore[arg-type]
            completed_at=job.completed_at,          # type: ignore[arg-type]
        )


    @router.post("/jobs", response_model=JobResponse, status_code=201)
    async def enqueue_job(
        request: Request,
        body: JobEnqueueRequest,
        db: AsyncSession = Depends(get_db),
        auth: tuple = Depends(verify_hmac),
        redis: aioredis.Redis = Depends(get_redis_client),
    ):
        """Enqueue a microflow job for execution.

        Accepts inline microflow YAML + optional payload + optional idempotency_key.
        Creates a WorkerJob record (status=queued) and enqueues an ARQ job.
        """
        tenant_id, signed_key = auth
        if tenant_id is None:
            raise HTTPException(status_code=401, detail="Authentication required")

        # Create job record
        job = WorkerJob(
            tenant_id=tenant_id,
            microflow_yaml=body.microflow_yaml,
            payload=body.payload,
            idempotency_key=body.idempotency_key,
            status="queued",
            max_retries=5,
        )
        db.add(job)
        await db.flush()

        # Enqueue ARQ job
        from ccam_backend.redis_client import arq_pool
        if arq_pool is None:
            raise HTTPException(status_code=503, detail="ARQ pool not initialized")

        await arq_pool.enqueue_job(
            "execute_microflow_job",
            body.microflow_yaml,
            body.payload,
            job.id,
            body.idempotency_key,
        )

        # Audit log
        logger = AuditLogger(db)
        await logger.log(
            tenant_id=tenant_id,
            action="job.enqueued",
            actor_type="api_key",
            actor_id=signed_key[:16] if signed_key else "unknown",
            target_type="worker_job",
            target_id=job.id,
            after={
                "microflow_name": None,  # Not parsed at enqueue time
                "idempotency_key": body.idempotency_key,
            },
        )

        await db.commit()
        return _job_to_response(job)


    @router.get("/jobs", response_model=JobListResponse)
    async def list_jobs(
        request: Request,
        db: AsyncSession = Depends(get_db),
        auth: tuple = Depends(verify_hmac),
        page: int = 1,
        page_size: int = 50,
        status_filter: str | None = None,
    ):
        """List worker jobs for the tenant, newest first.

        Optional status_filter: queued, running, completed, failed, dlq
        """
        tenant_id, _ = auth
        if tenant_id is None:
            raise HTTPException(status_code=401, detail="Authentication required")

        # Count
        count_query = select(func.count()).select_from(WorkerJob).where(
            WorkerJob.tenant_id == tenant_id,
        )
        if status_filter:
            count_query = count_query.where(WorkerJob.status == status_filter)
        total_result = await db.execute(count_query)
        total = total_result.scalar() or 0

        # Fetch page
        query = (
            select(WorkerJob)
            .where(WorkerJob.tenant_id == tenant_id)
            .order_by(WorkerJob.created_at.desc())
            .offset((page - 1) * page_size)
            .limit(page_size)
        )
        if status_filter:
            query = query.where(WorkerJob.status == status_filter)
        result = await db.execute(query)
        jobs = result.scalars().all()

        items = [_job_to_response(j) for j in jobs]
        return JobListResponse(items=items, total=total)


    @router.get("/jobs/{job_id}", response_model=JobResponse)
    async def get_job(
        request: Request,
        job_id: str,
        db: AsyncSession = Depends(get_db),
        auth: tuple = Depends(verify_hmac),
    ):
        """Get a specific worker job by ID with its status and result."""
        tenant_id, _ = auth
        if tenant_id is None:
            raise HTTPException(status_code=401, detail="Authentication required")

        result = await db.execute(
            select(WorkerJob).where(
                WorkerJob.id == job_id,
                WorkerJob.tenant_id == tenant_id,
            )
        )
        job = result.scalar_one_or_none()
        if job is None:
            raise HTTPException(status_code=404, detail="Job not found")

        return _job_to_response(job)
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API | Untrusted client sends HTTP requests to the FastAPI backend. HMAC authentication applied. |
| API→Worker (ARQ/Redis) | Internal boundary — enqueue endpoint writes to Redis via ARQ pool. Worker reads from same Redis. No direct client access. |
| Worker→Database | Worker function writes job status/result to PostgreSQL for persistence and queryability. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | DoS | POST /api/v1/jobs | mitigate | HMAC auth prevents anonymous enqueue; microflow_yaml size bounded by Pydantic (implied reasonable limit 1MB); worker step limit prevents runaway execution |
| T-04-02 | Spoofing | ARQ job enqueue | mitigate | enqueue_job is internal (not exposed to clients); only the authenticated endpoints can trigger enqueue via arq_pool.enqueue_job() |
| T-04-03 | Tampering | WorkerJob status | mitigate | Status transitions are server-only via SQLAlchemy; no client-accessible status update endpoint |
| T-04-04 | Info Disclosure | GET /api/v1/jobs | mitigate | All queries tenant-scoped by `tenant_id`; cross-tenant access returns 404 |
| T-04-05 | Repudiation | Audit logging | mitigate | All job enqueue actions logged via AuditLogger with actor identity |
| T-04-06 | Elevation of Privilege | Worker memory | accept | Worker function runs with full DB access (same credentials as backend). No sandboxing applied per D-01 (MCF-03 deferred). Workers are trusted internal processes. |
| T-04-07 | DoS | DLQ overflow | accept | DLQ is same DB table with `dlq` status; tenant-scoped. No automatic cleanup in v1 — acceptable for early phase. |
